How it works

Upload attestation.tlsn, presentation.tlsn, and request.json produced by traceseal-core prove.
2
Cryptographic verification
The backend runs the pinned TLSNotary verifier in a separate process. Only a VERIFIED result is stored.

Look up any evidence ID, download artifacts, and trigger a fresh verifier run at any time.

Documentation

About TRACESEAL and this console.

What TRACESEAL does

TRACESEAL converts a live HTTPS response into cryptographically verifiable evidence using TLSNotary MPC-TLS. A proof package (attestation.tlsn, presentation.tlsn, request.json) is verified by a pinned TLSNotary verifier; only verified evidence is stored with a canonical commitment and a ts1_ identifier.

Trust model & limitations

  • Demo attestor key is public test material — not production trust.
  • Single-user local deployment; no authentication or multi-user ownership.
  • Fixture endpoints only: https://localhost:4443/trace-seal-{503,200,404,delay}, TLS 1.2.
  • Hedera anchoring is planned, not implemented.
